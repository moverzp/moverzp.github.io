题目

先看一下env.yml中配置的package，需要的package有jupyter, matplotlib, numpy, python37, sklearn，如果我们的环境已经安装了这些package，就不需要创建新的环境并下载，否则使用conda env create -f env.yml命令创建新的环境并安装这些package，使用conda activate a2激活该环境。

有一点需要注意，公式推导的时候，词向量是列向量，矩阵也是一个个列向量组成的，但是在程序实现的时候，词向量是行向量，矩阵也是一个个行向量组成的，因此编码实现的公式其实是Written部分推导的公式的转置。

下面我们来填充.py文件需要填充的部分。

a.4 skipgram()

实现word2vec的skip-gram模型。

传入的参数有：

  • currentCenterWord，string，中心词
  • WindowSize，int，采集上下文词汇的窗口大小
  • OutsideWords，list，上下文单词的列表，长度不会超过2倍的窗口大小
  • word2Ind，dict，key是单词，value是单词的索引
  • centerWordVectors，ndarray，中心词的嵌入矩阵，即矩阵$\boldsymbol V$
  • outsideVectors，ndarray，上下文词的嵌入矩阵，即矩阵$\boldsymbol U$
  • word2vecLossAndGradient，function，传入预定的参数，可以计算返回loss，loss对中心词的偏导数，loss对上下文词的嵌入矩阵的偏导数

返回的变量有

  • loss，skip-gram损失
  • gradCenterVecs，skip-gram损失函数对中心词的嵌入矩阵的偏导数，即$\frac {\partial \boldsymbol J}{\partial \boldsymbol V}$
  • gradOutsideVecs，skip-gram损失函数对上下文的词嵌入矩阵的偏导数，即$\frac {\partial \boldsymbol J}{\partial \boldsymbol U}$
  • 通过下标在词嵌入矩阵中取词向量，和one-hot词向量乘以词嵌入矩阵效果一样
  • 针对每一个context word，都要算一次loss和grad
  • 每算一次loss和grad，都要累加新的loss和grad

返回的变量有：

  • x，完成SGD后的参数

小结

  • coding部分最主要的就是计算loss和grad，通常情况下，计算loss和grad也是训练模型的关键
    • 能计算出loss，需要确定模型结构，根据具体的目标设计损失函数；能计算出grad，说明loss function可导，而且可以使用SGD求极小值
  • 训练结束后，矩阵$V$就是词嵌入矩阵，通过单词的下标或者one-hot向量相乘，就可以得到单词的词向量
  • 只是输入了python run.py，然后模型就开始训练了，不清楚从头到尾训练的细节，只知道怎么计算loss和grad，始终有种意犹未尽的感觉，所以如果想消除这种意犹未尽的感觉，请看CS 224n(2019) Assignment 2: word2vec[Coding]——Part 2
